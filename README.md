# 听写小助手 · Dictation Buddy

> 版本：V0.3.2（修复拍照确认选区、预览与重新框选，新增手机端检查更新）
>
> 本工具独立于《宝可梦太晶战术图鉴》，采用相同的 **静态网页 + GitHub Pages + PWA** 方案。手动输入、词库管理及播报无需自建服务器或苹果开发者账号。若要使用专用云端手写识别，需要另行部署 OCR 转发服务并配置密钥。静态网页无需安装 Node.js，也不需要编译。

## 一、功能

- **两种平级的词语输入方式**：打开“词库 → 导入”时默认选择“手动输入”，也可以切换至“拍照识别”。
- **手动输入**：支持一个词、一行一个词、批量粘贴；可以选择按标点或空格拆分。英文词组建议保留“一行一个”。
- **拍照识别**：调用手机相机或相册，先拖动蓝色框圈定选区，点击底部始终可见的「确认选区」，检查裁剪预览，再点「开始识别文字」，识别结果进入可编辑文本框。**印刷体**使用 Tesseract.js 浏览器识别；**手写体**需配置专用云识别 Worker 接口，不能把印刷体 OCR 当成可靠的手写识别。
- **保存前逐条核对**：下一步预览每一项，支持纠错、移除、补充新词；中文还能点亮某个或多个汉字，指定需要写拼音。
- **词库管理**：命名、增删、编辑、多词库勾选、全选；**每一份已有词库卡片上都提供“手动输入添加”与“拍照识别添加”两个按钮**。新增词语会追加到原词库，不创建第二份、也不覆盖原词；重复词自动跳过，已保存的练习组合引用不受影响。
- **组合**：跨多份词库勾选词语，保存为练习组合，或加入已有组合；同时支持中英文混合组合。
- **播报**：按顺序或随机；每词重复 1–5 次；可调同词重复间隔、词间书写时间、中英文语速；暂停、继续、上下词、重听与显隐答案。
- **拼音提示**：某个中文词的指定字标记后，先报词语，再提示“请写出第1个字和第2个字的拼音。”不会把拼音答案读出来。
- **本机数据与 JSON 备份**：无需注册，词库保存在当前浏览器的本地存储，支持导出、导入备份。备份包含拼音字位与组合成员。

## 二、部署到 GitHub Pages（推荐）

1. 在电脑上解压本项目 ZIP 文件。
2. 登录 GitHub，新建一个**单独仓库**，例如 `dictation-buddy`。不要放到现有的宝可梦图鉴仓库，以免影响已经上线的页面。
3. 将解压得到的文件 **直接上传到仓库根目录**（不要只上传 ZIP，也不要在根目录外再套一层文件夹）。确保根目录有 `index.html`、`app.js`、`core.js`、`styles.css`、`sw.js`、`manifest.webmanifest` 和 `assets/`。
4. 打开仓库 **Settings → Pages → Build and deployment**，选择 `Deploy from a branch`，将分支设为 `main`，目录设为 `/ (root)`，保存。
5. 在 Pages 设置页找到网页地址，形式一般为 `https://你的GitHub用户名.github.io/dictation-buddy/`。这是**示例格式，不是已开通的网页链接**。
6. 用 iPhone 的 Safari 打开发布后的实际地址，再通过“分享 → 添加到主屏幕”安装，之后从主屏幕进入。

V0.3.2 起，应用「设置 → 应用版本与更新」提供 **检查更新** 和 **立即更新**：新版本仍需先上传部署至同一个 GitHub Pages 地址，更新按钮才能获取到版本。网页刷新或应用重启后会载入新版本。请同时上传 `version.json`、`version-utils.js` 与 `sw.js`，否则更新检查不能正常工作。

**V0.3.1 升级到 V0.3.2 的第一次**，由于 V0.3.1 尚无检查更新按钮，仍需通过 GitHub Pages 覆盖上传最新版文件，然后在 iPhone 用 Safari 打开同一网址刷新一次。V0.3.2 之后才可以直接在「设置」内检查新版。

**不要为了升级删除主屏幕应用或清除网站数据。** 词库仅保存在当前浏览器/主屏幕容器，更新不会主动删除本地数据，但因平台存储机制，建议升级前导出 JSON。静态网页部署需要 HTTPS；直接打开本地 `index.html` 不能完整验证 PWA、模块导入或 OCR。

## 三、建议的使用流程

1. 第一次先进入“词库 → ＋导入”，选择 **手动输入**、中文，把 `崎岖`、`拥抱`、`坚韧` 分别输入一行。
2. 点“下一步 · 核对词语和拼音标记”；对“崎岖”点“标拼音”，选择“崎”“岖”两个字，然后点“确认并保存词库”。
3. 给已建的中文词库继续加词时，无需新建：直接在该词库卡片点 **“手动输入添加”** 或 **“拍照识别添加”**，核对后保存，就会追加到这份词库。新建英语词库则每行输入 `wonderful`、`take care of`、`environment`。
4. 返回“词库”，展开两份词库，勾选需要复习的项，点击“存为组合”。
5. 进入“组合”，点击“开始听写”，设置播报顺序、次数、间隔，然后点击“开始播报”。
6. 进入“设置”可调整中英文音色及语速、试听和导出备份。

## 四、使用边界与隐私

- **程序更新**：在「设置 → 应用版本与更新」检查 GitHub Pages 上的 `version.json`，有新版本时触发 Service Worker 更新并重新载入页面。不会修改本地词库 JSON 或清空 localStorage。iPhone 仍有缓存与网络环境差异，建议先备份。
- **不是云同步工具**：Safari 与主屏幕 App 可能采用不同的数据容器；换手机、清理浏览器数据、卸载主屏幕应用，都可能导致本地词库丢失。请定期导出 JSON 备份。
- **离线能力有边界**：网页外壳会在首次成功访问后尝试使用 Service Worker 缓存；手动输入和词库数据无需应用自建服务器。印刷体 OCR 使用第三方 CDN 的 JS / WebAssembly / 语言文件，首次使用必须联网，后续离线 OCR 不作保证；手写体云端识别必须联网。
- **图片处理方式**：印刷体识别在浏览器本地处理裁剪后的图片；手写体使用配置好的 HTTPS OCR Worker 时，**仅裁剪区域**会上传至该服务和下游识别提供商。当前压缩包不包含云端 Worker 服务端代码、已部署的云服务或密钥，未配置时无法使用手写识别。请勿把服务密钥写进公开 GitHub 仓库。网络受限时可使用相册“实况文本”复制粘贴，或直接手动输入。
- **听写播报**：调用浏览器 Web Speech API，依赖 iPhone 已安装的语音和 Safari 支持。**锁屏、切后台后不保证持续播报**。建议亮屏、前台使用；不同 iOS 版本与音色可能读音不同，请先试听。
- **OCR 识别有误差**：尤其是多栏表格、低清晰度、书本弯曲、复杂标点、多音字。请在“逐条核对”页检查。英语词组在“每行一个”的拆分模式下不会被拆散。
- **已验证与未验证**：已通过 Node.js 纯业务逻辑测试和 Chromium 模拟移动界面交互检查；尚未进行真实 iPhone Safari 设备验收，OCR/CDN、语音实际听感与后台行为必须在用户手机上测试。

## 五、开发结构

```
index.html                页面入口
styles.css                移动端布局
app.js                    页面交互、OCR、语音、词库与备份
core.js                   纯业务逻辑（导入拆分、批量追加去重、排序、拼音提示、数据校验）
ocr-utils.js              识别接口及裁剪参数校验
sw.js                     PWA 静态资源缓存 / 更新切换
version.json              远端最新版本说明（上传 GitHub Pages）
version-utils.js          版本号比较纯函数
manifest.webmanifest      主屏幕应用清单
assets/                   应用图标
/tests/core.test.mjs      不需要上传也可用，`node --test tests/core.test.mjs` 运行测试
```

## 近期功能与本版新增

- 自动连续播报全部选中词语，播完自动结束；词间隔快捷选择 3、5、8、10 秒，仍可用滑杆选 1–20 秒。
- 默认词间隔改为 5 秒（已有本地设置不会覆盖）。

- V0.3.1 新增：在每个已有词库卡片中提供两种添加入口，批量追加并自动跳过与原词库重复的词语；保留手动删除及核对页“一键去重”。V0.3 系列提供区域裁剪，以及云端手写 OCR 接口的前端适配，但云端服务需另行部署和配置，实际 iPhone 识别准确率仍需验收。

## V0.3.2 选区确认修复

1. 进入词库 → 拍照识别添加，选择相机或相册里的照片。
2. 在蓝色选框上拖动角点调整文字范围；向下滚动也不会隐藏页面底部的「✓ 确认选区」。
3. 点击 **「✓ 确认选区」**，查看裁剪后的照片预览。框外内容不会送入 OCR。
4. 如果范围不正确，点击 **「重新框选」**；范围正确则点击 **「第 2 步 · 开始识别文字」**。
5. 识别文字追加到下方输入框，继续「下一步 · 核对词语和拼音标记」。

备注：印刷体使用本机 OCR，手写体必须先配置专用云端识别接口。未配置手写服务时，仍可完成选区确认和预览，但点击识别会提示缺少接口，**不会假装成功或用印刷体引擎代替**。

### 升级验证

- 浏览器测试：相册选图后按钮出现在滚动内容之外；可确认 → 预览 → 重新框选。
- 更新机制：同一个 GitHub Pages 地址发布后检查 `version.json`；Service Worker 预取新版资源后更新缓存，用户点击「立即更新」重新加载网页；不会触碰 `localStorage` 数据。
- 未在真实 iPhone Safari 设备上验证，请以实机操作结果为准。
