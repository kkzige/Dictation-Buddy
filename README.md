# 听写小助手 · Dictation Buddy

> 版本：V0.1.1（iPhone 网页 / PWA 验证版）
>


## 一、功能

- **两种平级的词语输入方式**：打开“词库 → 导入”时默认选择“手动输入”，也可以切换至“拍照识别”。
- **手动输入**：支持一个词、一行一个词、批量粘贴；可以选择按标点或空格拆分。英文词组建议保留“一行一个”。
- **拍照识别**：调用手机相机或相册，用 Tesseract.js 在浏览器里识别中文或英文，结果填进可编辑文本框。首次 OCR 需联网下载程序及对应语言包。
- **保存前逐条核对**：下一步预览每一项，支持纠错、移除、补充新词；中文还能点亮某个或多个汉字，指定需要写拼音。
- **词库管理**：命名、增删、编辑、多词库勾选、全选。
- **组合**：跨多份词库勾选词语，保存为练习组合，或加入已有组合；同时支持中英文混合组合。
- **播报**：按顺序或随机；每词重复 1–5 次；可调同词重复间隔、词间书写时间、中英文语速；暂停、继续、上下词、重听与显隐答案。
- **拼音提示**：某个中文词的指定字标记后，先报词语，再提示“请写出第1个字和第2个字的拼音。”不会把拼音答案读出来。
- **本机数据与 JSON 备份**：无需注册，词库保存在当前浏览器的本地存储，支持导出、导入备份。备份包含拼音字位与组合成员。

## 二、部署到 GitHub Pages（推荐）

1. 在电脑上解压本项目 ZIP 文件。
2. 登录 GitHub，新建一个**单独仓库**，例如 `dictation-buddy`。不要放到现有的宝可梦图鉴仓库，以免影响已经上线的页面。
3. 将解压得到的文件 **直接上传到仓库根目录**（不要只上传 ZIP，也不要在根目录外再套一层文件夹）。确保根目录有 `index.html`、`app.js`、`core.js`、`styles.css`、`sw.js`、`manifest.webmanifest` 和 `assets/`。
4. 打开仓库 **Settings → Pages → Build and deployment**，选择 `Deploy from a branch`，将分支设为 `main`，目录设为 `/ (root)`，保存。
5. 在 Pages 设置页找到网页地址，形式一般为 `https://你的GitHub用户名.github.io/dictation-buddy/`。这是**示例格式，不是已开通的网页链接**。
6. 用 iPhone 的 Safari 打开发布后的实际地址，再通过“分享 → 添加到主屏幕”安装，之后从主屏幕进入。

如通过 GitHub Pages 更新了代码，请关闭旧窗口并刷新页面，以加载最新版本。静态网页部署需要 HTTPS；直接打开本地 `index.html` 不能完整验证 PWA、模块导入或 OCR。

## 三、建议的使用流程

1. 第一次先进入“词库 → ＋导入”，选择 **手动输入**、中文，把 `崎岖`、`拥抱`、`坚韧` 分别输入一行。
2. 点“下一步 · 核对词语和拼音标记”；对“崎岖”点“标拼音”，选择“崎”“岖”两个字，然后点“确认并保存词库”。
3. 新建一份英语词库，每行输入 `wonderful`、`take care of`、`environment`。
4. 返回“词库”，展开两份词库，勾选需要复习的项，点击“存为组合”。
5. 进入“组合”，点击“开始听写”，设置播报顺序、次数、间隔，然后点击“开始播报”。
6. 进入“设置”可调整中英文音色及语速、试听和导出备份。

## 四、使用边界与隐私

- **不是云同步工具**：Safari 与主屏幕 App 可能采用不同的数据容器；换手机、清理浏览器数据、卸载主屏幕应用，都可能导致本地词库丢失。请定期导出 JSON 备份。
- **离线能力有边界**：网页外壳会在首次成功访问后尝试使用 Service Worker 缓存；手动输入和词库数据无需应用自建服务器。OCR 使用第三方 CDN 的 JS / WebAssembly / 语言文件，首次使用必须联网，后续离线 OCR 不作保证。
- **图片处理方式**：图片在浏览器端交给 Tesseract.js 识别；本应用未设置自有图片上传 API。OCR 程序从第三方内容分发网络下载；网络受限时可用 iPhone 相册的“实况文本”复制并粘贴，或直接手动输入。
- **听写播报**：调用浏览器 Web Speech API，依赖 iPhone 已安装的语音和 Safari 支持。**锁屏、切后台后不保证持续播报**。建议亮屏、前台使用；不同 iOS 版本与音色可能读音不同，请先试听。
- **OCR 识别有误差**：尤其是多栏表格、低清晰度、书本弯曲、复杂标点、多音字。请在“逐条核对”页检查。英语词组在“每行一个”的拆分模式下不会被拆散。
- **已验证与未验证**：已通过 Node.js 纯业务逻辑测试和 Chromium 模拟移动界面交互检查；尚未进行真实 iPhone Safari 设备验收，OCR/CDN、语音实际听感与后台行为必须在用户手机上测试。

## 五、开发结构

```
index.html                页面入口
styles.css                移动端布局
app.js                    页面交互、OCR、语音、词库与备份
core.js                   纯业务逻辑（导入拆分、排序、拼音提示、数据校验）
sw.js                     PWA 静态资源缓存
manifest.webmanifest      主屏幕应用清单
assets/                   应用图标
/tests/core.test.mjs      不需要上传也可用，`node --test tests/core.test.mjs` 运行测试
```
