# 听写小助手 V0.3.7｜内置 Dir_OP / Dir_EP 音乐与中文音色试听

**升级基础：** V0.3.4 免注册版本。识别服务本轮不变；手动录入仍然优先，完全不需要百度智能云或 Cloudflare。

## 本版新增

1. **开场**：如果已配置 `Dir_OP.mp3`，先完整播放该音乐；否则使用约 1.3 秒的原始提示音。随后以中文语音说「准备好了吗？现在开始听写。」；短暂停顿后自动播报第一个词。
2. **结束**：最后一个词和中文拼音提示都播完后，优先完整播放 `Dir_EP.mp3`（未配置时使用短提示音），再朗读「本次听写已完成。辛苦了！」；语音结束后界面显示「全部完成」。
3. **中文 / 英文可分别选择系统音色和语速**，并可以直接在听写开始前试听，不用到别处找设置。新增「清晰慢速」「自然速度」预设。默认新用户中文 0.80×、英文 0.78×；旧用户已有语速会保留，按「清晰慢速」后中文为 0.80×、英语为 0.75×。
4. **高级微调**：展开「微调音高、音量」调整中英文音高（0.85–1.15）和语音音量（20%–100%）。音乐音量单独可调（0%–80%）。
5. **提示独立开关**：开场音乐+语音、结束音乐+语音可以分别关闭；可以试听短音乐。
6. **保留原有核心播报设置**：每词 1–5 遍、同一个词的重复间隔（0–5 秒）、不同词语间的书写时间（1–30 秒，3/5/8/10 秒快捷按钮）、顺序/随机、拼音提示、暂停/继续、重听和自动播完。
7. **继续保留独立的 `manual.html` 手动录入入口**，支持中文按空格分词、英文一行一个短语、已有词库追加、去重和核对。修正了旧 Service Worker 错把手动录入页存成首页离线缓存的问题。

## 如何使用

进入 iPhone 听写小助手 → **「听写」**：

- 前四块是原来的重复次数、重复间隔、书写时间、顺序。
- **⑤ 发音选择与清晰度微调**：选中文/英语音色，调整各自语速，点「试听中文 / 试听英文」。更多设置点「微调音高、音量」。
- **⑥ 开始与结束提示**：按需打开或关闭音乐+提示语，调音乐音量。
- 点击「开始播报」，自动完成整组听写；结束后给出音乐和语音提示。

**默认建议：** 中文 0.80×，英文 0.75–0.80×，音高 1.00，语音音量 100%，音乐音量约 38%，每词 2 遍，重复间隔 1 秒，词间书写时间 5–10 秒。适合孩子听写练习，可以根据朗读是否清楚逐步微调。

## 更新 GitHub Pages

1. 先从旧版「设置」导出一次 JSON 备份，确认原词库仍在。
2. 将 ZIP 解压，把**网页程序文件**上传到**原来的听写小助手 GitHub 仓库根目录**覆盖旧版本（不是宝可梦图鉴仓库）。保持 `assets/` 目录结构，**务必上传 `manual.html`、`sw.js`、`version.json`、`app.js`、`core.js` 等文件**。
3. GitHub Pages 部署完成后，使用原来的 Safari 网站地址打开，确认顶部版本显示 `v0.3.7`。必要时在网址结尾加 `?v=037` 刷新；无须卸载主屏幕应用或清除 Safari 网站数据。
4. 到「听写」页任选一份词库，分别点「试听开始音乐」「试听结束音乐」，分别试听中文和英语音色，再用 2 个词进行完整播报验收。
5. 后续发布新版后仍可在「设置 → 应用版本与更新」中检查与安装已发布的更新。

## 兼容与限制

- **音频文件为可选**：若未配置 MP3，两段短提示音由 Web Audio API 合成，旋律为本项目原创；如果配置了 MP3，则使用指定文件。
- 发音依赖 iPhone Safari 当前可用的系统语音。设备支持的声音才会出现在下拉列表；如只显示「系统自动选择」，先点击「刷新音色列表」尝试。不同设备的发音清晰度会不同。
- iOS Safari 可能限制语音或音频在没有用户点击、锁屏或后台情况下连续播放。请在前台保持屏幕亮着，首次使用点页面上的播放按钮；如果系统中断，点「继续」重新朗读当前段。**未承诺锁屏连续播放**。
- 程序不会主动删除原词库。`localStorage` 的存储键仍为 `dictation-buddy-v0.1-data`，原组合、拼音标记、语速和书写时间都保留；新增设置会在第一次载入时用默认值补齐。
- 拍照 OCR 与手写识别 **本版没有调整**，仍优先使用手动输入/复制文字。

## V0.3.7 音乐文件安装（重要）

**文件对应：** `Dir_OP.mp3` 是开始音乐；`Dir_EP.mp3` 是结束音乐。程序保证先播放完整 MP3（监听媒体 `ended`），再朗读对应提示语。若选中的 MP3 不能播放，会提示并使用内置短音乐替代。

### 方法 A：在 iPhone 上直接设置（无需电脑，也不必再更新 GitHub）
本安装包已内置真实的 `assets/audio/Dir_OP.mp3`（开始音乐）和 `assets/audio/Dir_EP.mp3`（结束音乐）。更新到 V0.3.7 后，无需再手动选入这两首音乐；程序会优先自动使用它们。若你以后想替换成别的音乐，也仍可在「听写」页中手动选择新的 MP3，本机选择会优先于内置文件。

### 方法 B：随程序一起发布（电脑上传）
因为本次安装包已经包含这两个 MP3，上传 GitHub Pages 时请保留 `assets/audio/` 目录及其中的音乐文件。这样所有设备打开页面即可直接使用；但如果某台手机已选过本机 MP3，则本机选择仍然优先。

**本更新包未附带用户的两段实际 MP3**，因为这段聊天中仅看到文件名，没有收到可读取的音频文件；不应假装已经内置。请自行通过方法 A 选择，或把原文件附到对话以便之后真正打包。若要发布到公共仓库，请确保音乐有合法的网络分发使用权限。

### 中文音色说明

新增可展开的音色试听清单，按 Safari 返回的 `zh-*` 声线展示，包含普通话/台湾国语/粤语标签；点击「试听」可先听，点击「选用」可保存。**不能凭网页凭空增加 Apple 没开放给 Safari 的音色**；即便系统安装了某个 Siri 声线，也可能不对网页开放。英语音色选择、语速音高音量、词间书写时间、重复间隔、1—5 遍播放都保留。建议优先普通话 zh-CN，语速约 0.75—0.85。
