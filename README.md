# 听写小助手 V0.3.5｜开场/结束提示与发音微调

**升级基础：** V0.3.4 免注册版本。识别服务本轮不变；手动录入仍然优先，完全不需要百度智能云或 Cloudflare。

## 本版新增

1. **开场**：用户点击「开始播报」后，播放一段约 1.3 秒的原创四音提示旋律；随后以中文语音说「准备好了吗？现在开始听写。」；短暂停顿后自动播报第一个词。
2. **结束**：最后一个词和中文拼音提示都播完后，播放另一段短旋律，再朗读「本次听写已完成。辛苦了！」；语音结束后界面显示「全部完成」。
3. **中文 / 英文可分别选择系统音色和语速**，并可以直接在听写开始前试听，不用到别处找设置。新增「清晰慢速」「自然速度」预设。默认新用户中文 0.80×、英文 0.78×；旧用户已有语速会保留，按「清晰慢速」后中文为 0.80×、英语为 0.75×。
4. **高级微调**：展开「微调音高、音量」调整中英文音高（0.85–1.15）和语音音量（20%–100%）。音乐音量单独可调（0%–80%）。
5. **提示独立开关**：开场音乐+语音、结束音乐+语音可以分别关闭；可以试听短音乐。
6. **保留原有核心播报设置**：每词 1–5 遍、同一个词的重复间隔（0–5 秒）、不同词语间的书写时间（1–30 秒，3/5/8/10 秒快捷按钮）、顺序/随机、拼音提示、暂停/继续、重听和自动播完。
7. **继续保留独立的 `manual.html` 手动录入入口**，支持中文按空格分词、英文一行一个短语、已有词库追加、去重和核对。修正了旧 Service Worker 错把手动录入页存成首页离线缓存的问题。

## 如何使用

进入 iPhone 听写小助手 → **「听写」**：

- 前四块是原来的重复次数、重复间隔、书写时间、顺序。
- **⑤ 发音选择与清晰度微调**：选中文/英语音色，调整各自语速，点「试听中文 / 试听英文」。更多设置点「微调音高、音量」。
- **⑥ 开始与结束提示**：按需打开或关闭音乐+提示语，调音乐音量。
- 点击「开始播报」，自动完成整组听写；结束后给出音乐和语音提示。

**默认建议：** 中文 0.80×，英文 0.75–0.80×，音高 1.00，语音音量 100%，音乐音量约 38%，每词 2 遍，重复间隔 1 秒，词间书写时间 5–10 秒。适合孩子听写练习，可以根据朗读是否清楚逐步微调。

## 更新 GitHub Pages

1. 先从旧版「设置」导出一次 JSON 备份，确认原词库仍在。
2. 将 ZIP 解压，把**网页程序文件**上传到**原来的听写小助手 GitHub 仓库根目录**覆盖旧版本（不是宝可梦图鉴仓库）。保持 `assets/` 目录结构，**务必上传 `manual.html`、`sw.js`、`version.json`、`app.js`、`core.js` 等文件**。
3. GitHub Pages 部署完成后，使用原来的 Safari 网站地址打开，确认顶部版本显示 `v0.3.5`。必要时在网址结尾加 `?v=035` 刷新；无须卸载主屏幕应用或清除 Safari 网站数据。
4. 到「听写」页任选一份词库，点「试听提示音乐」，分别试听中文和英语音色，再用 2 个词进行完整播报验收。
5. 后续发布新版后仍可在「设置 → 应用版本与更新」中检查与安装已发布的更新。

## 兼容与限制

- **不需要音频文件或联网音乐**：两段短音乐由 Web Audio API 在浏览器本机合成，旋律是为本项目新写的，不包含第三方版权音乐。
- 发音依赖 iPhone Safari 当前可用的系统语音。设备支持的声音才会出现在下拉列表；如只显示「系统自动选择」，先点击「刷新音色列表」尝试。不同设备的发音清晰度会不同。
- iOS Safari 可能限制语音或音频在没有用户点击、锁屏或后台情况下连续播放。请在前台保持屏幕亮着，首次使用点页面上的播放按钮；如果系统中断，点「继续」重新朗读当前段。**未承诺锁屏连续播放**。
- 程序不会主动删除原词库。`localStorage` 的存储键仍为 `dictation-buddy-v0.1-data`，原组合、拼音标记、语速和书写时间都保留；新增设置会在第一次载入时用默认值补齐。
- 拍照 OCR 与手写识别 **本版没有调整**，仍优先使用手动输入/复制文字。
